# Лендинг Tetradent TiS

Готовый статический лендинг на HTML5, CSS3 и Vanilla JavaScript. Сборка не требуется.

## Структура

```text
index.html
assets/
  css/styles.css
  js/main.js
  images/
  icons/
  fonts/
```

## Локальный запуск

В PowerShell из папки проекта:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Публикация

### GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. В GitHub откройте Settings - Pages.
3. Выберите Deploy from a branch.
4. Укажите ветку `main` и папку `/root`.

### Обычный хостинг

Загрузите `index.html` и папку `assets` в корневую папку сайта. Сохраняйте текущую структуру путей.

## Подключение CRM

В файле `assets/js/main.js` заполните константу:

```js
const FORM_ENDPOINT = "https://example.ru/api/lead";
```

Форма отправляет JSON с полями `name`, `phone` и `source`. Пока адрес пустой, интерфейс честно показывает техническое сообщение и не имитирует успешную отправку.

## Что заменить перед финальной публикацией

1. Пара фотографий для блока результатов. Сейчас шторка «до/после» собрана из одного склеенного кадра `case-before-after-user.webp`: слои кадрируются по замеренным окнам и сводятся по лицу. Если появится настоящая пара (одинаковый ракурс, одинаковый масштаб лица, одинаковая высота рта в кадре, 1600x1200), подмена займёт четыре строки - поменять два `src` и заменить правила `.ba-layer--after img` / `.ba-layer--before img` на `width:100%; height:100%; object-fit:cover; left:0; top:0`. Разметка, скрипт и доступность не меняются.
2. Значение `FORM_ENDPOINT` для подключения CRM.
3. `og:image`, если сайт будет опубликован не на домене `stom.tetradent.ru`.
4. Растровый `tetradent-logo.png` можно заменить на точный SVG без изменения разметки.

## Проверки

- Якорное меню и мобильное меню.
- Единое модальное окно для CTA.
- Закрытие модального окна по кнопке, Escape и клику по фону.
- Focus trap и возврат фокуса.
- Маска российского телефона и сообщения ошибок.
- Блокировка повторной отправки.
- `prefers-reduced-motion`.
- Адаптивные состояния для 360, 768, 1024, 1440 и 1920 px.
- Семантика, alt-тексты, label, видимый focus и JSON-LD Dentist.
- Шторка «до/после»: перетаскивание мышью и пальцем, клик в точку, стрелки и Home/End, вертикальная прокрутка страницы поверх шторки.
- Без JavaScript: контент виден, линия этапов залита, шторка стоит на 50/50, цифры в блоке врача показывают исходные значения.
