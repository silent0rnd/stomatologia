# Лендинг Tetradent TiS

Готовый статический лендинг на HTML5, CSS3 и Vanilla JavaScript. Сборка не требуется.

## Структура

```text
index.html
assets/
  css/styles.css
  js/main.js
  images/
  icons/
  fonts/
```

## Локальный запуск

В PowerShell из папки проекта:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Публикация

### GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. В GitHub откройте Settings - Pages.
3. Выберите Deploy from a branch.
4. Укажите ветку `main` и папку `/root`.

### Обычный хостинг

Загрузите `index.html` и папку `assets` в корневую папку сайта. Сохраняйте текущую структуру путей.

## Подключение CRM

В файле `assets/js/main.js` заполните константу:

```js
const FORM_ENDPOINT = "https://example.ru/api/lead";
```

Форма отправляет JSON с полями `name`, `phone` и `source`. Пока адрес пустой, интерфейс честно показывает техническое сообщение и не имитирует успешную отправку.

Первый экран:

- `tetradent-logo.png`, `favicon.png` - логотип из приложенного референса пользователя.

- `case-2.webp` - 3D-модель челюсти, исходник `b5a24e38.png.webp`.

- `case-5.webp` - работы лаборатории, исходник `57c1599d.png.webp`.

Внешних горячих ссылок на фотографии нет. Карта подключена отдельным iframe Яндекс Карт из текущей страницы.

## Что заменить перед финальной публикацией

1. Четыре изображения в блоке результатов. На текущей странице нет подтверждённых пар фотографий пациентов до и после. Сейчас показаны реальные иллюстрации этапов лечения с честным пояснением.
2. Значение `FORM_ENDPOINT` для подключения CRM.
3. `og:image`, если сайт будет опубликован не на домене `stom.tetradent.ru`.
4. Растровый `tetradent-logo.png` можно заменить на точный SVG без изменения разметки.

## Проверки

- Якорное меню и мобильное меню.
